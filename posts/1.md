## Introduction
SCAXE is a fork of **[iTXTech/Genisys](https://github.com/iTXTech/Genisys)** . Only support Minecraft: Pocket Editon v0.14.x - 0.15.x.

Our goal is to achieve a **stable, high-performance, and feature rich** server software in MC:PE

## Features
- **High Performance:**
	- With support for PHP8 JIT and high-performance extension of PMMP, SCAXE has much higher performance than Genisys.
 	- SCAXE has good multi-threaded support, which can alleviate a considerable amount of lag caused by chunk loading/sending/saving.
  	- SCAXE uses Composer, and compatible with the latest version of PMMP modules, bringing many performance improvements and new features
  	- Optimized packet systems can achieve higher packet compression rates with less overhead (≈ 80% before optimization=>≈ 30% after optimization | excluding block sending compression), and can also easily decompose packets into protocol zones

- **vanilla game features:** 
	- In version 0.14, neither Genisys nor Nukkit provided rich support for the original features. SCAXE has improved this(better generator/entity AI, redstone/hopper/anvil/map support), but many features are still not implemented.
	- SCAXE also fixes many bugs/feature errors in Genisys, allowing players to have a better experience with fewer crashes.

- **Security:**
	- SCAXE has fixed many memory leaks and crash factors in early servers, and it is very stable compared to other servers at 0.14. (ToolBox and network attacks can easily crash Genisys0.14, Leopard cat can crash Nukkit0.14)
 	- SCAXE can effectively prevent server cheating and hacking, and can defend against many cheats in 0.14
 	- SCAXE provides a variety of performance analysis tools (async timings, WatchDog, Packet dumper) that can effectively find the problem location when the server is stuck/memory leaked/packet attacked

- **Muti-Version:**  SCAXE is the only server that supports interoperability between major versions 0.12. x-0.15. x

## 介绍
SCAXE 是 **[iTXTech/Genisys](https://github.com/iTXTech/Genisys)** 项目的分支。支持我的世界携带版 v0.12.x - 0.15.x.

我们的目标是实现一个 **稳定、高性能、功能丰富** 的MC:PE服务端

## 特性
- **高性能:**
	- 在PHP8 JIT和PMMP高性能扩展的加持下, SCAXE 的性能比Genisys高很多
 	- SCAXE有良好的多线程支持，可以极大的缓解由区块加载、发送、保存导致的延迟
  	- SCAXE使用Composer, 并且可以兼容PMMP模块，这带来了很多新功能和性能提升
  	- 经过优化的数据包系统可以用更少的开销来实现更高的数据包压缩率(优化前≈80% => 优化后≈30%  | 排除区块发送压缩)，还可以非常便捷的实现协议区分解包

- **原版特性丰富:**
	- Nukkit0.14和Genisys0.14都没有良好的原版特性支持. SCAXE很大的改进了这一点（世界生成器、实体AI、红石、漏斗、铁砧、地图)，但是很多原版特性仍然有待实现
	- SCAXE同时修复了很多Genisys的bug/特性谬误，可以让玩家在更少崩溃的情况下活动更好体验

- **安全性:**
	- SCAXE修复了早期服务端中很多的内存泄漏与崩服因素, 并且比0.14服务端更加稳定. (ToolBox和网络攻击可以轻松瘫痪Genisys0.14, 豹猫可以让Nukkit0.14崩服)
 	- SCAXE提供了有效的服务端反作弊，可以防御0.14中绝大部分的外挂
 	- SCAXE提供丰富的性能分析工具(async timings, WatchDog, Packet dumper) 可以在服务端遭到卡顿/内存泄露/数据包攻击时有效的找到问题发生地点

- **多版本支持:** SCAXE是唯一支持0.12.x - 0.15.x大版本互通的服务端
