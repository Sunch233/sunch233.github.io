# 你还在为改客户端时 GLSL着色器、jsonUI 报错，但是需要手动排查而感到烦恼吗?

使用 **MCPE 0.14.3 Sunch Client** 精准定位报错内容

**MCPE 0.14.3 Sunch Client**是一个专为 0.14.3客户端开发者/玩家 设计的mod客户端，具有以下特性(1.1.2版本)：

- `帧数显示`: 游戏内左上角显示当前fps
- `垂直同步`: 自由开关vsync，解锁帧数限制 (注意: 帧数过高时触碰无法蹲下)
- `游戏内信息显示`: 类似java版WTHIT mod的效果，游戏内顶部显示正在查看的方块、实体信息
- `动态光源`: 字面意思
- `强制疾跑`: 前进时默认疾跑
- `兼容鼠标输入`: 完整安卓鼠标支持
- `更多错误处理`: 在jsonUI、glsl着色器进行解析、编译时出现错误自动报告。避免反复排查
- `json UI 布局调试`: 直观的在游戏内看见各种ui控件的信息，内容，方便更改

# 客户端开发特色功能

## glsl着色器错误处理

原版 0.14 在着色器编译失败时是没有任何提示的：不弹窗、不写日志，受影响的材质直接不渲染。改 `text.fragment` 这种全屏文字材质的时候，表现往往就是"进游戏看着一切正常，但字没了"，然后你只能靠注释掉一整段再重进来的二分法去找问题。

Sunch Client 在编译失败的那一刻就把引擎侧的信息原样弹出来：

## jsonUI 错误处理

JSON UI 比着色器更隐蔽 —— 它没有编译期。`type` 写错、控件名拼错、引用了不存在的属性，原版一律表现为**那个控件静默不出现**，游戏不报错、日志里也没有，你只能对着界面猜是哪块没渲染出来。
